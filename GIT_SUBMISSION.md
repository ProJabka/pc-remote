# Состав репозитория

В GitHub опубликованы исходный код, документация и APK:

- `android/` — Android Studio проект;
- `server/` — HTTPS-сервер и тесты;
- `release/PC-Remote.apk` — готовое приложение;
- `docs/` — скриншоты и отчёт проверки;
- `README.md` — инструкция запуска.

Презентация для защиты хранится отдельно и намеренно не входит в GitHub.
