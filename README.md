# PC Remote — доступ к файлам ПК с Android

PC Remote состоит из Android-приложения и HTTPS-сервера для Windows.
Телефон получает доступ только к выбранной папке компьютера: можно просматривать
каталоги, искать файлы, скачивать их на телефон, загружать файлы на ПК и создавать папки.

## Возможности

- подключение по Wi-Fi / локальной сети или через личный VPN;
- просмотр вложенных папок и поиск по текущему каталогу;
- скачивание файлов через системный Android Document Picker;
- загрузка файлов с телефона на ПК;
- создание папок;
- HTTPS с проверкой SHA-256 отпечатка сертификата;
- секретный ключ доступа для каждого запроса;
- хранение данных подключения через Android Keystore;
- режим сервера «только чтение».

Удаление, перезапись и запуск файлов на компьютере намеренно не поддерживаются.
Это файловый доступ, а не удалённый рабочий стол.

## Быстрый запуск сервера

Из каталога проекта запустите:

```powershell
.\start-server.cmd
```

По умолчанию открывается только `shared/`. Для другой папки:

```powershell
.\start-server.cmd -Root "D:\Мои документы"
```

В окне сервера появятся адрес, ключ доступа и SHA-256 отпечаток.
Эти данные вводятся в Android-приложении.

Телефон и ПК должны находиться в одной сети. Для доступа вне дома используйте
личный VPN и не открывайте порт сервера всему интернету.

## Android-приложение

Готовый APK находится в разделе Releases:

https://github.com/ProJabka/pc-remote/releases/tag/v1.0.0

Исходный Android-проект находится в `android/`. Откройте эту папку в Android Studio.
Минимальная версия Android — 8.0 (API 26).

Сборка:

```powershell
.\build-apk.cmd
```

Результат появится в `dist/PC-Remote.apk` и `release/PC-Remote.apk`.

## Структура репозитория

```text
android/              исходный проект Android Studio
server/               HTTPS-сервер и интеграционные тесты
shared/               пример общей папки
release/PC-Remote.apk готовый APK
docs/                 скриншоты и отчёт проверки
start-server.cmd      запуск сервера Windows
build-apk.cmd         сборка APK
```

Презентация для защиты хранится отдельно от GitHub по требованию преподавателя.
